# Memory Governance

Status: **canonical current invariant**

Lantern separates remembering from asserting, and asserting from authorising action.

The human or organisation operating a deployment remains the ultimate authority for that deployment. A configured Foreman may perform routine bounded review. Extractors, Dreamer, semantic matchers and external agents may identify or propose material, but they do not establish canonical truth by themselves.

## Promotion boundary

Uncertain, creative or merely useful material belongs in a soft Memory Item.

A factual Claim requires:

- evidence;
- perspective/provenance;
- a usable predicate or an explicit unmapped state;
- a governed reconciliation step.

Unknown predicates remain unknown rather than being silently promoted.

## Corrections are additive

A correction is a new evidence event.

It preserves the old Source, Episode, Claim and Belief lineage; adds correction evidence and a new Claim; invalidates or supersedes the affected current projection; and marks dependent projections stale when necessary.

Historical truth is not deleted merely because current understanding changed. Current retrieval should prefer active projections, while historical retrieval may explicitly request superseded or prior views.

## Governance records

Proposal and Trace records provide the review/audit boundary. Foreman decisions are bounded and traceable. Supported outcomes can include accept, reject, modify and defer.

A candidate generator or external AI cannot directly mutate canonical Beliefs.

## Authority remains separate

Memory governance does not grant execution authority.

A remembered instruction, Belief, Context Pack or model-generated candidate cannot create an `AuthorityGrant`. Authority mutation follows its own authenticated, auditable path.

This prevents context from becoming permission by accident.

## Migration boundary

Imported memory stores are evidence/migration sources, not permanent semantic authorities. Import accounting should make unexplained loss, duplication and attribution changes visible.
