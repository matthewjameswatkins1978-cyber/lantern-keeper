# Lantern Keeper First Proof

## The Human Relay Problem

When a person copies context out of one AI tool and pastes it into another, they
become the integration layer.  That is slow, error-prone, and unnecessary.
Lantern Keeper acts as a shared, local memory so that AI tools can pass relevant
context directly — the human should not manually carry context between AI tools.
